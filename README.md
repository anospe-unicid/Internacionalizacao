# Atividade Prática de Internacionalização em Android Studio

Este projeto consiste numa aplicação Android desenvolvida para demonstrar a implementação de internacionalização (suporte a múltiplos idiomas e regiões) e organização de recursos de interface de utilizador.

## 🚀 Funcionalidades e Aprendizagem

- **Internacionalização (i18n):** Estruturação do projeto para suporte a múltiplos idiomas utilizando ficheiros de recursos (`strings.xml`).
- **Gestão de Layout e Dimensões:** Padronização de margens, tamanhos e espaçamentos através de `dimens.xml`.
- **Compatibilidade:** Configuração de temas e recursos visuais para adaptação dinâmica do sistema.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **IDE:** Android Studio
- **Sistema de Build:** Gradle (Kotlin DSL)
- **Controlo de Versões:** Git / GitHub

## 📁 Estrutura do Projeto

- `app/src/main/res/values/`: Ficheiros de recursos padrão.
- `app/src/main/res/values-pt/`: Recursos traduzidos para a língua portuguesa.
